## Qualification method proposed for review

1. Identify the precise investment entity, SEC filer, mandate and accountable team. Match the performance entity to the filing entity; disclose any proxy mismatch. Exclude an unresolved mismatch from purchase eligibility.
2. Use the latest fully published annual report available at the decision timestamp. Prefer an audited fund report and confirm whether the performance schedule itself is within the audit scope. Record the report title, publication date, measurement period, page/table, share class, currency, fees, benchmark and source URL.
3. Prefer a common five-year period; require at least three complete years. Compute both portfolio and benchmark compound annual growth rates from comparable total-return series: `CAGR = (ending total-return value / starting total-return value)^(1 / years) - 1`. For annual percentage returns use `product(1 + return/100)^(1 / years) - 1`. Never average annual returns arithmetically or compare different periods/currencies. Prefer net-of-fee fund returns and a documented dividend-reinvested benchmark.
4. Require investor CAGR strictly above the comparable benchmark CAGR and explicit source verification. Do not estimate missing manager performance from 13F market values: flows, omitted assets and disclosure delays invalidate that shortcut. The current evidence schema stores this qualification as an operator-verified attestation, not an independently validated return series.
5. Compare the latest two complete, published, consecutive 13F quarters available **as of** the decision time. Verify legal manager, accession, acceptance/publication date, reporting period, amendments, CUSIP, security class, splits and ADR ratios. Do not use a future filing or assume a missing row means liquidation. As of 10 November, September-quarter filings may still be outstanding; select only filings actually published, not an assumed completed quarter.
6. Keep the current rubric: a verified positive share change gives institutional 100, unchanged gives 50, negative gives 0. Independent analysis awards 25 points each for positive revenue growth, positive free cash flow, interest coverage at least 3 and positive 90-day price return. Composite = `0.60 × institutional + 0.40 × independent`. These weights are policy choices, not evidence of predictive performance. The model currently supports one selected verified manager per security; multi-manager aggregation requires a separately documented policy before implementation.
7. Preserve source dates, captured-at timestamp, expiry and provenance in each decision's evidence snapshot. Incomplete/expired qualification blocks purchases. Independent -8% stops remain available with validated trade prices and the existing execution guards.

## Boundary for this review

This proposal does not activate a manager, change the benchmark, import evidence or change trading thresholds. The next implementation stage is source verification, selection of a qualified manager/security mapping, quarterly/TTM financial support and scheduled ingestion with safe retry and failure diagnostics. The existing 120-day financial freshness rule and all purchase risk controls remain in force. BAE requires verified IFRS/ADR coverage. Until these are complete, the system remains safe to evaluate and record decisions but is not a completed autonomous investment-data service.
